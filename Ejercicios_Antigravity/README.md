# 💡 Ejercicios Resueltos de Estructuras de Datos (Pilas y Colas)
**Creados por Antigravity para el Campus de Programación en Java y C++**

Esta sección complementa el campus web con ejercicios resueltos de la vida real sobre **Pilas (Stacks)** y **Colas (Queues)**.

---

## 📂 Contenido del Módulo

### ☕ Java (`Ejercicios_Antigravity/Java/`)
1. `Ejercicio1_Pila_CtrlZ.java`: Pila (Stack) simulando el botón Deshacer (Ctrl+Z) con `push()`, `pop()`, `peek()`.
2. `Ejercicio2_Cola_Banco.java`: Cola (Queue) simulando la fila de atención de un banco con `offer()`, `poll()`, `peek()`.
3. `Ejercicio3_InvertirPalabra.java`: Pila utilizada para invertir el orden de cualquier cadena de texto (propiedad LIFO).
4. `Ejercicio4_ParentesisBalanceados.java`: Verificador de anidamiento de paréntesis, corchetes y llaves `{ [ ( ) ] }`.

### ⚡ C++ (`Ejercicios_Antigravity/C++/`)
1. `ejercicio1_pila_ctrlz.cpp`: Mismo ejercicio de Pila en C++ usando `std::stack` (`push()`, `top()`, `pop()`).
2. `ejercicio2_cola_banco.cpp`: Mismo ejercicio de Cola en C++ usando `std::queue` (`push()`, `front()`, `pop()`).
3. `ejercicio3_invertir_palabra.cpp`: Mismo ejercicio de invertir texto en C++.
4. `ejercicio4_parentesis_balanceados.cpp`: Mismo ejercicio de verificación sintáctica en C++.

## 🌐 Visualización Interactiva en la Web
Para ver las explicaciones interactivas, diagramas y comparativas lado a lado:
1. Abre tu navegador en **http://localhost:3000** (o ejecuta `abrir_web.bat`).
2. Haz clic en la pestaña superior **"💡 Ejercicios Antigravity"**.
3. Navega por cada ejercicio en el menú lateral o con los botones superiores.
